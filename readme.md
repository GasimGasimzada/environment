# Gasim environment

## Installation

1. Clone this repo to `~/.config/gasim` directory
2. `cd install`
3. For linux, run `sh setup-linux.sh`
4. For macOS, run `sh setup-macos.sh`
5. For Windows, run `pwsh setup-windows.ps1`

## Commands

### `git-clean-repo`

Deletes all local branches and prunes all pulled remote branches

```sh
git-clean-repo
```

### `git-amend`

Amends previous git commit without editing commit message

```sh
git-amend
```
