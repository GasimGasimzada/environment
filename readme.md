# Gasim environment

## Installation

1. Clone this repo to `~/.config/gasim` directory
2. `cd install`
3. For macOS, run `sh setup-macos.sh`

## Shell defaults

The following configs are configured for each shell

| App             | ZSH | Bash | Powershell |
| --------------- | --- | ---- | ---------- |
| Oh-My-Posh      | ✅  | ✅   | ✅         |
| Zoxide (cd = z) | ✅  | ✅   | ✅         |
| FNM             | ✅  | ✅   | ✅         |
| Menu completion | ✅  | ✅   | ✅         |

## Neovim

LSP binaries need to be installed manually.

| Language   | Required binary             |
| ---------- | --------------------------- |
| Typescript | typescript-language-server  |
| Oxlint     | oxc_language_server         |
| Tailwind   | tailwindcss-language-server |
| Lua        | lua_language_server         |
